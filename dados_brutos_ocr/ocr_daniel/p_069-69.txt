CORTE AQUI

DO PALÁCIO AO PASTO

= 1. Que declaração fez o rei Nabucodonosor a respeito de Deus? Daniel 4:3
( ) Ele declarou que Deus não existe.

( ) Ele exaltou as obras de Deus e reconheceu que o Seu domínio é eterno.

( ) Nabucodonosor disse que as obras de Deus são obscuras e más.

() Nenhuma das alternativas.

= 2. O que trouxe espanto ao rei Nabucodonosor? Daniel 4:5
( ) Um sonho.

( ) Uma tempestade de granizo.

( ) Uma severa seca e escassez de alimentos.

( ) A notícia de que uma crise de fome se espalhava pelo império.

= 3. Que pessoas foram novamente chamadas para decifrarem o sonho? Daniel 4:7
( ) Daniel e seus amigos.

( ) Os governadores de Babilônia.

() Os príncipes e princesas das províncias.

() Os magos, os encantadores, os caldeus e os feiticeiros.

= 4. O que Nabucodonosor sonhou? Daniel 4:10-17

()O rei viu uma grande árvore. Ela dava muito fruto, e todos os seres viventes se mantinham dela.

( ) Um vigilante disse que a árvore deveria ser derrubada e os seus ramos cortados.

( ) Haveria mudança do seu coração humano para um coração de animal e assim se passariam 7 tempos.
( ) Todas as alternativas estão corretas.

= 5. Segundo a interpretação de Daniel o que aconteceria ao rei? (Daniel 4:20-22, 25)

( ) A árvore, que representava o próprio rei, seria derrubada, dando a entender que ele perderia o domínio
de seu trono temporariamente.

( ) O rei seria expulso da vida social e moraria com os animais do campo por 7 tempos, ou seja, 7 anos.
(/) O rei deveria reconhecer que o Altíssimo tem domínio sobre o reino dos homens e o dá a quem quer.
() Todas as alternativas estão corretas.

= 6. Que declaração feita pelo rei trouxe-lhe o juízo divino? (Daniel 4:30, 31)

( ) Quão grandes são os seus sinais, e quão poderosas, as suas maravilhas!

( ) O Teu reino é reino sempiterno, e o Teu domínio, de geração em geração.

() “Não é esta a grande Babilônia que edifiquei [...] com o meu poder e para glória da minha majestade?”
( ) Nenhuma das alternativas.

= 7. Após os sete anos de loucura, o que reconheceu o rei Nabucodonosor? Daniel 4:34-37
( ) Reconheceu que Deus não pode humilhar os que andam na soberba.

( ) Reconheceu que somente o Altíssimo é Deus e que o Seu domínio é eterno.

( ) Reconheceu que as obras de Deus não são verdadeiras.

( ) Nenhuma das alternativas.
